  1. פותחים את הפרויקט בפורמה
  2. פותחים את חנות התוספים: App Store
  3. לוחצים על גלגל השיניים בפינה ובוחרים: Find extension by ID
  4. מדביקים את המזהה ומאשרים
  5. התוסף מופיע ברשימת התוספים של הפרויקט

ההתקנה היא לכל פרויקט בנפרד. בפרויקט שהתוסף כבר מותקן בו אין צורך להתקין שוב, גם ממחשב אחר עם אותו חשבון.

מתוך התוסף עצמו, כפתור השיתוף בראש החלונית, ליד ההגדרות, מעתיק את המזהה.

English
  1. Open the project in Forma
  2. Open the App Store
  3. Click the gear icon → Find extension by ID
  4. Paste the ID above and confirm

Extensions are installed per project. Inside the extension, the share icon next to Settings copies the ID.
