# o2a Massing Studio

Autodesk Forma extension for o2a-studio: massing variations, setbacks and GFA (שטח ברוטו), planning compliance (תב״ע / detailed design), and sun, noise and wind analysis.

This repository hosts the built extension for GitHub Pages at
https://omerbarr.github.io/o2a-massing-studio/

Opened in a normal browser tab, the page reports that it cannot connect to Forma. That is expected: it only runs inside Forma, from the Extensions menu of the o2a hub.
